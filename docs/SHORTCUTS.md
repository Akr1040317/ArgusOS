# Shortcuts & Command Palette

Global:
- Cmd+K: command palette
- Cmd+1..5: tabs (Command Center, Inbox, Calendar, Chat, Settings)
- Cmd+F: focus search
- ?: shortcut overlay
- Esc: close overlay/palette

Inbox:
- J/K: next/prev thread
- Enter: open thread
- R: focus Draft panel editor
- Shift+R: regenerate draft
- T: cycle tone (concise/warm/assertive/formal)
- C: copy draft
- A: archive (if enabled)
- L: label menu (later)

Palette commands:
- Go to Inbox/Calendar/Chat/Settings
- Search threads…
- Summarize current thread
- Generate draft for current thread
- Run agent now
