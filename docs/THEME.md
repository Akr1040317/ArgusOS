--panel #0C1020

--text-0 #EAF0FF

Rules:
- Subtle separators, minimal outlines
- Active row: slightly lighter bg + left accent bar
- Hover: small bg lift, no heavy shadows
- Optional: gradient only on primary call-to-action and focused input ring
